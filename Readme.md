# Online Logistics System  

## Project Domain / Category  
Web Application  

## Abstract / Introduction  
Logistics is a vital part of supply chain management, ensuring goods move efficiently from suppliers to manufacturers and sellers. With the digital transformation, logistics companies are moving online, offering real-time booking, tracking, and visibility to enhance decision-making and operational efficiency.  

The **Online Logistics System** streamlines logistics operations by enabling online booking, route tracking, shipment management, income and expense tracking, and report generation.  

## Functional Features  
- **User Features:**  
  1. Account creation with essential details like name, address, phone number, and email.  
  2. Freight booking and rate calculation based on weight and selected cities.  
  3. Online payment for shipments.  
  4. Route tracking for shipments.  

- **Admin Features:**  
  1. Manage vehicles, drivers, and trip details.  
  2. Track company expenses (fuel, maintenance, salaries, etc.).  
  3. Record and manage income details.  
  4. Generate income and deduction reports monthly or on demand.  
  5. Activate/deactivate cities for freight bookings and set rates per city.  
  6. Print reports for operational insights.  

- **Rate Calculator:**  
  Users can calculate freight rates by selecting origin, destination, and entering weight for accurate cost estimation.  

## Tools and Technologies Used  
- **Frontend:** HTML, CSS, Bootstrap, JavaScript, jQuery  
- **Backend:** PHP, Laravel  
- **Database:** MySQL  
- **Additional Libraries:** jQuery Datatables  

## Key Highlights  
- Fully functional admin panel for streamlined logistics management.  
- User-friendly interface for seamless freight bookings and payments.  
- Real-time shipment tracking for users.
